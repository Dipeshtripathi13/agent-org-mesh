# Published artifacts (local copies)

Standalone HTML snapshots of pages published via Claude's Artifact tool this session — kept
here so they survive past the scratchpad. Each is self-contained (open directly in a
browser, no server needed).

- **guide-for-you.html** — end-user guide to the app, written for someone who's never seen
  it before, with real screenshots.
- **technical-reference.html** — technical reference for the codebase, written for a
  developer picking this project up.
- **market-fit-memo.html** — market/positioning research: category fit, competitive
  landscape, required modifications, and buyer personas (2026-08-20).

These are point-in-time snapshots — if the app or plans change, the live pages will drift
from what's captured here. Re-publish and re-copy if you want an updated snapshot.
